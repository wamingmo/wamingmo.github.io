Created2026-09-13|Updated2026-09-13|chore

2026.07.11

这个时候就适合写点什么。

为什么呢？因为计博的校赛没过。

现在的状况是什么呢？

准备科保：需要一个国二才能参加科保的答辩，我现在还没有国二。

科保算分有四个部分：学习成绩（40%）、代表成果（40%）、综合考核（20%）、附加分

算法分别如下：

  • 1-加权百分比（现在是25.4%，也就是74.6）
  • 因为我没有论文，所以这部分就是竞赛算分：竞赛基础分×奖项分×排名分
  • 答辩分

竞赛基础分：三大赛：100、智能车/节能减排/robocon/robomaster：90、其他：80

奖项分：国一：100%，国二：90%

排名：队长：100%，前50%：90%，后50%：80%

  • 附加分：针对除代表成果外的其他竞赛获奖或论文，上限为 3 分，单项竞赛或论文最高为 1.5 分，最多计算两项成果，计算方式、范围和要求参考“代表成果”部分，在成果得分的基础上乘以 1.5%。

本来的多重准备：

  • 计博——作为队长拿国二/一（代表成果：80×100%×100% = 80或80×90%×100% =72）
  • 编译——作为队员（后50%）拿国二/一（代表成果：80×100%×80% =64 或80×90%×80% =57.6）
  • 国创赛——作为队员（前50%）拿国二/一（代表成果：100×100%×90% = 90或100×90%×90% = 81）

本来的分数：

  • 第一种：74.6×0.4 + 80×0.4 = 61.84 或 74.6×0.4 + 72×0.4 = 58.64
  • 第二种：74.6×0.4 + 64×0.4 = 55.44 或 74.6×0.4 + 57.6×0.4 = 52.88
  • 第三种：74.6×0.4 + 90×0.4 = 65.84 或 74.6×0.4 + 81×0.4 = 62.24

听学长说，答辩分数相差不大

听同学说，去年的科保成功的同学，不算答辩分似乎在61+

现在的情况：

  • 计博校赛没过，不能参加国赛，也就是第一条路断了
  • 第二条路算出来分很低（本来准备当附加分的）
  • 第三条路：今年的国创赛推迟了，不确定什么时候能出结果。

**夏令营相关：**按照原来准备科保的计划，我积极准备参加夏令营，已经：1、通过了软件所国重的初筛，13-14号进行线下的笔试和面试 2、已经套磁了计算所处理器芯片重点实验室的老师，老师说可以“霸面”给我面试机会，也已经报名了计算所的夏令营。

**综上：**科保变成了未知数，且似乎有很大概率保不上。我不确定是不是要现在准备考研？
